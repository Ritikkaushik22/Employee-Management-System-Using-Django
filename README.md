# 🧑‍💼 Employee Management System (Django CRUD)

This is a Django-based web application that implements a full **CRUD (Create, Read, Update, Delete)** interface for managing employees.


## 📌 Features

- ✅ Add new employees (via form on the homepage)
- 📋 View all employees in a table
- ✏️ Update employee details (on a separate edit page)
- ❌ Delete employees directly from the list
